# Deep-Mix v1.1.0

Release date: 2026-08-18

v1.1.0 is the first feature release after the clean v1.0.0 public snapshot. It was assembled from private source commit `f0404c2b962b1a338ab1a599887d9e593192b52a` into the separate public history; private plans, evaluation evidence, runtime state, credentials, personal paths, and internal screenshots remain excluded.

## Highlights

- Configurable `governor`, `coding`, and `vision` model slots replace fixed provider-role assumptions.
- The `classic` preset preserves DeepSeek-, GLM-, and Kimi-compatible profile names without making them permanent runtime contracts.
- Profiles now expose protocol, adapter, allowed-slot, and capability metadata; trusted Profile Service APIs redact credentials, sensitive headers, and URL query data.
- Version 2 settings add revisioned compare-and-swap writes, explicit migration previews, ordered fallbacks, capability requirements, and immutable assignment snapshots.
- Runtime state moves to `~/.deep-mix/workspaces/<workspace-id>/` by default, so opening a repository no longer creates runtime state in it. `DEEP_MIX_HOME` changes the user-state root.
- Desktop adds model-profile editing, configurable shortcuts, revised settings/navigation, slash-command discovery, improved session/title flows, and tighter attachment/message presentation.

## Compatibility and migration

- Version 1 settings and legacy `ds_direct`, `glm_coding`, and `kimi_vision` routes remain readable. Saving a migration is explicit; loading never rewrites the source file.
- Project `.deep-mix/settings.json`, MCP, Skills, Workflows, and legacy profile files remain valid explicit inputs. New runtime state and newly saved workspace credentials prefer user-level state.
- The new `packages/model-adapters` and `packages/state-location` workspaces are private monorepo packages and share the repository version.

## Security and dependencies

- `fast-uri` is pinned to `3.1.5`; the transitive Nano ID 3.x line is updated to a patched release.
- The public source vendors the official PptxGenJS 4.0.1 CommonJS/ES bundles, type declaration, and MIT license without its unused `image-size` dependency. No published `image-size` release fixed the ICNS/JXL/HEIF infinite-loop advisories at release time, while Deep-Mix's presentation boundary already accepts only bounded in-memory PNG/JPEG images.
- Full and production `npm audit` report zero known vulnerabilities at release time.
- Profile secrets remain outside settings, renderer state, conversation history, logs, telemetry, exports, artifacts, and normal tool results.

## Known limitations

- Source release only: no signed installer, auto-update channel, or packaged binary is attached.
- The permission layer is not an OS sandbox. Approved native code runs with the current user's privileges.
- Managed background processes remain experimental and disabled by default.
- Windows is the primary verified platform; Linux and macOS coverage remains narrower.
- Provider API behavior, model availability, pricing, and data policy are external and can change independently of this release.
