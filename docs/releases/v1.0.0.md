# Deep-Mix v1.0.0

Release date: 2026-07-26

v1.0.0 is the first public source release of Deep-Mix. It starts from a clean Git history and excludes private development plans, evaluation evidence, local runtime state, credentials, and personal filesystem paths.

## Highlights

- One DeepSeek governor for conversation, planning, routing, supervision, and final response
- Isolated GLM coding and Kimi vision workers that return typed artifacts
- Shared CLI and Electron Desktop runtime
- Permission modes, persisted approvals, checkpoints, rollback, undo, and session resume
- Modular built-in tool registry with capability-aware selection
- Local Skills, deterministic Workflows, and MCP extension boundaries
- Repository, Git, shell, web, document, spreadsheet, presentation, notebook, archive, and quality tooling
- Full public architecture, security, configuration, usage, testing, and contribution documentation

## Compatibility

- Node.js: 22.12 or newer
- npm: 10 or newer
- Primary verified OS: Windows 10/11 with PowerShell
- Release form: source code; no signed installer
- State/config schema version: 1

Provider endpoints and model names are configured locally and are not a compatibility guarantee. The required governor must expose the chat/tool-call behavior expected by the DeepSeek adapter.

## Security changes for public release

- `.deep-mix` runtime data is denied by default in Git, with only public boundary files allowlisted.
- Provider profiles use an ignored `profiles.local.json`; examples reference environment variables.
- Managed background-process tools are registered but unavailable by default.
- The security model explicitly states the absence of OS-level sandboxing and descendant-process containment.
- Electron and build tooling were upgraded for the release.
- Spreadsheet support uses `@mui/x-internal-exceljs-fork@5.0.0` through the alias name `exceljs`, removing the obsolete vulnerable dependency chain of upstream `exceljs@4.4.0`.

The final tag records the exact checked source. CI repeats the public release gate without provider credentials.

## Known limitations

- Deep-Mix is not a sandbox and runs with the current user's OS privileges.
- Managed processes lack Job Object/cgroup/namespace containment; malicious descendants can escape lifecycle tracking.
- Windows is the only fully exercised platform for process-heavy behavior at this release.
- Desktop is a development source entry, not a signed packaged application.
- Live provider behavior, pricing, model availability, and data retention are controlled by third parties.
- Session exports and local runtime state are not automatically safe to publish.
- Checkpoints do not reverse arbitrary commands or remote side effects.
- Full-suite duration and availability depend on host capabilities; the default `npm test` command is intentionally a smaller deterministic gate.

## Upgrade note

This public repository does not import the private pre-release Git history or local `.deep-mix` state. Treat it as a new clone. If you manually copy a pre-release profile or settings file, keep secrets local and review every field against [Configuration](../configuration.md).
