# Code of Conduct

Deep-Mix contributors are expected to make the project welcoming, safe, and technically constructive.

## Expected behavior

- Be respectful and assume good intent while still reviewing claims critically.
- Discuss code, evidence, trade-offs, and impact rather than attacking people.
- Welcome contributors with different experience levels and backgrounds.
- Respect privacy; never publish another person's credentials, private data, or identifying information.
- Accept maintainer decisions on scope, safety, and release readiness without harassment.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, doxxing, sustained disruption, and deliberate exposure of secrets or private repository material are not tolerated in project spaces.

## Enforcement

Report conduct concerns privately through the maintainer's GitHub profile. Maintainers may edit or remove content, lock discussions, reject contributions, or temporarily or permanently restrict participation. Reports will be handled as confidentially as practical.

This policy applies to repository discussions, issues, pull requests, reviews, and project-related public spaces.
