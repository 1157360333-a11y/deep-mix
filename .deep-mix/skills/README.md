# Skills Boundary

`Skills` are reusable knowledge and process instructions. A skill may explain how to perform work, which files to read first, which scripts to run, and which constraints to preserve.

Skills do not directly provide external system access. If a task needs live GitHub, browser, database, or other external actions, that capability belongs in `MCP`, not in a skill.

Project skills are discovered from `.deep-mix/skills/<skill-name>/SKILL.md`. Compatibility skills are also discovered from `.agents/skills/`.
